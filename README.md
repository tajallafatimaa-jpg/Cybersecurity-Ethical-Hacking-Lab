# Cybersecurity-Ethical-Hacking-Lab

Practical cybersecurity and ethical hacking laboratory environment designed for learning, experimentation, and hands-on security practice.

## Overview

This project demonstrates the setup and configuration of a practical cybersecurity lab using VirtualBox, Kali Linux, and Windows virtual machines.

The lab provides an isolated environment for studying networking, system security, vulnerability assessment, and basic ethical hacking concepts.

## Lab Environment

- VirtualBox
- Kali Linux
- Windows Virtual Machine
- NAT Networking
- IP Configuration
- Connectivity Testing
- VM Snapshots

## Objectives

The main objectives of this project are:

1. Set up a virtual cybersecurity laboratory.
2. Install and configure Kali Linux.
3. Configure a Windows virtual machine.
4. Understand virtual networking.
5. Configure and identify IP addresses.
6. Test connectivity between virtual machines.
7. Create and manage VM snapshots.
8. Develop practical cybersecurity skills in a controlled environment.

## Tools & Technologies

| Tool | Purpose |
|---|---|
| VirtualBox | Virtual machine management |
| Kali Linux | Security testing and analysis |
| Windows VM | Target/test environment |
| NAT Network | Virtual network communication |
| Command Line | Network and system testing |

## Network Configuration

The lab uses virtual networking to allow communication between the virtual machines while maintaining an isolated testing environment.

Basic networking tasks include:

- Checking IP addresses
- Testing connectivity
- Configuring network adapters
- Using ping for connectivity testing
- Understanding virtual network modes

## VM Snapshots

Snapshots are used to save the current state of virtual machines.

They allow the lab environment to be restored to an earlier state after testing or configuration changes.
